# ComfyUI API workflows

Export the LTX-2.5 workflow from ComfyUI using the API-format export option and put its JSON file in this directory.

Do not commit model weights, API credentials, private endpoint URLs, or large workflow assets here. The workflow JSON should only contain node definitions and model references available in your ComfyUI installation.

The required prompt-node ID, image-input node ID and output-node IDs vary by workflow. Inspect the JSON before using the generation UI or CLI.
