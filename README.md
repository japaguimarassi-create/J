# Enturma AI

Integrated social conversation AI and Minecraft Forge 1.20.1 mod.

This branch is being prepared by a one-time source bootstrap: GitHub Actions validates the Python AI, validates the dialogue datasets, builds the Forge mod, stores the JAR as an artifact, and then expands the full source tree in this branch. The source archive is temporary and is removed after successful build.

If the bootstrap workflow fails, download enturma-ai-source.tar.gz and inspect the workflow logs before retrying.
