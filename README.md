# Zap Estourado

Gerador local de efeito sonoro meme com grito robótico/cartunesco sintetizado e distorção digital.

## Como usar

1. Abra `index.html` no navegador.
2. Ajuste a duração e a distorção.
3. Toque em **GERAR ÁUDIO**.
4. Baixe o arquivo WAV.

Sem API, servidor ou bibliotecas externas. O áudio é sintetizado no navegador usando Web Audio API e exportado em WAV mono, 44,1 kHz, PCM 16-bit.

O efeito é original e não reproduz o áudio do “gemidão do zap”. Comece com o volume baixo.
