MODULE 02 / DOCUMENTATION

Field guide

Practical reference for firmware status, the two-stage browser check and GoldHEN's role in a PS4 jailbreak.

01 / CURRENT STATUS

14.02 is not listed as jailbreakable

ConsoleMods' PS4 FAQ says there is no jailbreak for 14.02. The current chart lists 14.00 with a WebKit/kernel route and a Blu-ray route. PS4 Developer Wiki records the 14.00 AIO kernel vulnerability as patched on 14.02. G2All has a real 14.00 route, but its public launcher refuses versions above 14.00.

02 / WHAT GOLDHEN DOES

Exploit first, HEN second

GoldHEN is a Homebrew Enabler. It provides Debug Settings, FTP, Remote Package Install, Rest Mode support and plugins after it is loaded in a compatible environment. It is not a WebKit vulnerability, kernel exploit or permanent firmware patch. The upstream release page lists exact supported firmware versions.

03 / TWO-STAGE PREFLIGHT

Safe reload-based check

Stage one stores a session marker and reloads this site. Stage two checks common browser APIs and produces a report. It does not scan memory, test exploit primitives, send payloads, restart SceShellUI or change console configuration.

  1. Open the Preflight page from this host.
  2. Choose Start Pre-flight and allow one page reload.
  3. Review the browser-only checks and export the report if useful.
  4. A passed result means browser features are available, not that a jailbreak succeeded.
04 / ONLINE USE

Be careful with online jailbreak claims

Be wary of pages advertising permanent CFW, firmware downgrades, online unlocks or guaranteed PSN access. Never enter PSN credentials into a third-party host.

01 / STATUS ATUAL

14.02 não está listado como desbloqueável

O FAQ do ConsoleMods declara que não há jailbreak para 14.02. O gráfico atual lista 14.00 com uma rota WebKit/kernel e uma rota Blu-ray. O PS4 Developer Wiki registra a vulnerabilidade AIO de kernel de 14.00 como corrigida no 14.02. O G2All tem uma rota real para 14.00, mas o launcher público recusa versões acima de 14.00.

02 / O QUE O GOLDHEN FAZ

Exploit primeiro, HEN depois

GoldHEN é um Homebrew Enabler. Ele oferece Debug Settings, FTP, Remote Package Install, suporte ao Rest Mode e plugins depois de carregado em um ambiente compatível. Não é uma vulnerabilidade WebKit, exploit de kernel nem modificação permanente do firmware. A página oficial lista as versões compatíveis com cada build.

03 / PRÉ-VERIFICAÇÃO EM DUAS ETAPAS

Verificação segura com recarga

A etapa um grava um marcador temporário na sessão e recarrega o site. A etapa dois verifica APIs comuns do navegador e gera um relatório. Não examina memória, testa primitivas de exploit, envia payloads, reinicia o SceShellUI ou altera configurações do console.

  1. Abra a página Preflight neste host.
  2. Toque em Start Pre-flight e aguarde uma recarga.
  3. Confira os testes somente de navegador e exporte o relatório, caso necessário.
  4. Um resultado aprovado significa apenas que os recursos do navegador estão disponíveis; não significa que o jailbreak funcionou.
04 / USO ONLINE

Cuidado com promessas de jailbreak online

Desconfie de páginas que anunciam CFW permanente, downgrade, desbloqueio online ou acesso garantido à PSN. Nunca informe suas credenciais da PSN a um host de terceiros.
