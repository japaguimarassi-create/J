Guia do host

Como usar o painel no PS4, o que fica disponível offline e como interpretar as mensagens de compatibilidade.

Primeira utilização

  1. Abra o host pelo navegador do PS4.

    O User-Agent pode indicar a versão do sistema. Confirme em Configurações → Sistema → Informações do sistema.

  2. Permita a instalação do cache.

    Em navegadores legados compatíveis, o Application Cache armazena os arquivos do site. Aguarde o estado do cache e feche/reabra o navegador quando indicado.

  3. Use Host real somente se estiver em 14.00.

    O botão abre o GamerHack G2All original. O código de exploração não é copiado para este projeto.

  4. Interprete o resultado upstream.

    Uma mensagem de carregamento não comprova kernel liberado nem GoldHEN carregado.

Offline: duas tecnologias

PS4 Browser — Application Cache

O host usa um manifesto estático, adequado ao navegador legado do console. O cache é independente do Service Worker moderno.

Navegadores modernos — Service Worker

Quando disponível, o Service Worker é um complemento. A ausência dele no PS4 não significa que o cache legado falhou.

DualShock 4

Use a ordem natural dos elementos HTML. O direcional percorre links e controles como a tecla Tab; X ativa. Não é necessário que a Gamepad API esteja presente.

O que este site não faz

  • Não cria uma nova vulnerabilidade WebKit ou kernel.
  • Não instala GoldHEN sem uma cadeia compatível.
  • Não altera DNS ou configurações do sistema.
  • Não rebaixa firmware por software.
