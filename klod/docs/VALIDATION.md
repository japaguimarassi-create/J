# Twelve release confirmations

No item is approved merely because a component exists. Each needs reproducible evidence, a score of at least 8/10, and the overall average must be at least 8.5/10.

| # | Area | Evidence required | Status |
|---|---|---|---|
| 01 | Visual identity and organization | Screenshots and rubric | NOT RUN |
| 02 | Conversation interface | Mobile interaction evidence | NOT RUN |
| 03 | Navigation and history | Conversation CRUD tests | NOT RUN |
| 04 | Composer and attachments | Keyboard, upload and send tests | NOT RUN |
| 05 | Response rendering | Markdown, code and streaming tests | NOT RUN |
| 06 | Documents and artifacts | Create, open and export tests | NOT RUN |
| 07 | Projects | Project and file navigation tests | NOT RUN |
| 08 | Terminal and programming | Isolated execution, diff and test evidence | NOT RUN |
| 09 | Agent planning | Real task graph and continuation evidence | NOT RUN |
| 10 | Tools and permissions | Approved and denied operation tests | NOT RUN |
| 11 | General usability | Task-based usability results | NOT RUN |
| 12 | Android mobile comparison | Narrow, portrait, landscape, keyboard and gesture evidence | NOT RUN |

Any failure blocks APK generation. Never fabricate screenshots, tests, scores or evidence.
