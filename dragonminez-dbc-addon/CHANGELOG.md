# Changelog

## 0.1.0 — Initial playable foundation

- Added persistent Angel Lineage progression.
- Added Divine Sigil, Divine Altar, and Attendant Staff.
- Added Divine Instinct ability with energy, duration, cooldown, and evade chance.
- Added player HUD, status/admin commands, and server-to-client synchronization.
- Added safe DBC/JRMCore class-presence detection without mutating DBC internals.
- Added GitHub Actions build pipeline for Forge 1.7.10.

This release is an early playable prototype, not a complete replacement for DragonMine Z. Native DBC race selection, Glind/Angel model rendering, DBC Ki integration, dimensions, and questlines remain planned.
