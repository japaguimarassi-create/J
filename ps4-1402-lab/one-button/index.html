14.02
PRONTO

Uma execução por sessão. Os testes usam somente APIs públicas do navegador e não modificam o sistema do console.

O que esta versão faz: verifica APIs do navegador, testa operações locais pequenas, prepara cache quando suportado, registra evidências e tenta salvar uma cópia privada do relatório. O arquivo JSON também pode ser baixado para o celular ou para o armazenamento do console, conforme o navegador permitir.
Limite técnico: isso não é um HEN nem um jailbreak. Não há cadeia completa de 14.02 verificada neste projeto. A alegação pública de acesso parcial ao kernel relata kernel panic ao iniciar jogos e falha de inicialização do HEN/GoldHEN; por isso, esta página não executa essa cadeia.
O relatório não coleta cookies, credenciais, conteúdo da conta ou User-Agent completo. O firmware inferido pelo User-Agent é apenas uma indicação, não uma leitura confiável das configurações do PS4.
