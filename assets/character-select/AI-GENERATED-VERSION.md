# AI-generated icon sources

The current portraits were created and reviewed at game-icon size.

- Tanjiro final source: https://im.runware.ai/image/os/a02d21/ws/3/ii/1dc754af-2c64-4ce0-b5e1-bce7feaca9c3.jpg
- Muzan final source: https://im.runware.ai/image/os/a04d20/ws/3/ii/49dcd9b5-6441-47e7-85a4-7af125a032da.jpg

Muzan was regenerated from scratch using only the visual details in the user's supplied reference and the previously supplied Roblox drawn-head icon style: broad white hat with black band, pale square face, narrow red eyes, black wavy side curls, short jaw, thick ink contours and simple cel shading. A follow-up cleanup removed the small neck-like block so the portrait ends at the square chin. The previous elongated-face version was discarded. Tanjiro's portrait remains unchanged.

The GitHub Actions workflow imports both hosted portraits, validates square dimensions and minimum resolution, and rebuilds the faction preview.
