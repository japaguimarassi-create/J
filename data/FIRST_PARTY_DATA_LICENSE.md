# Deta first-party training examples — CC0 1.0

The synthetic programming prompts, planning examples, debugging scenarios, and short conversational examples generated by `scripts/build_instruction_corpus.py` in this repository are dedicated to the public domain under CC0 1.0 Universal, to the extent permitted by law.

These examples are authored for training the Deta app-programming assistant. They are not copied user conversations, do not contain credentials, and are not statements about a particular person's private information.

The examples teach a task format and implementation workflow; they do not define a fixed personality, self-description, or hidden system prompt for the deployed assistant. At runtime, the model receives the user's message and the application routes it by task intent.
