motionforge / AI← Studio

Crie imagens, vídeos e mundos 3D.

Um painel para os três geradores do MotionForge. Os modelos rodam no host de GPU configurado; o celular funciona como controle remoto.

SDXL · DIFFUSERS

Gerar imagem ou desenho

Texto para imagem ou imagem para imagem com um checkpoint SDXL.

LTX-2.5 · COMFYUI

Gerar vídeo

Envie um prompt ou anime uma imagem inicial usando um workflow API do ComfyUI.

O arquivo workflow deve existir em generation/workflows/. Os IDs dos nós variam de acordo com o workflow exportado. Acesso a pesos LTX pode exigir autorização e aceitação da licença.
HUNYUAN3D-2.1

Transformar imagem em 3D

Crie uma malha 3D a partir de uma imagem. Materiais PBR são opcionais.

O Hunyuan3D-2.1 declara cerca de 10 GB de VRAM para gerar a forma e 29 GB para forma + textura. A licença limita território e uso; os resultados não podem ser usados para melhorar outra IA.

MotionForge AI · Os arquivos gerados ficam no host de GPU. Modelos e pesos não são enviados ao Git. A qualidade e os limites dependem do checkpoint, da licença e do hardware disponível.
